# 项目入口片段（由 Agent 合并，不整段覆盖已有规则）

接入时用真实路径替换说明文字，保留项目特殊规则；宿主不读 AGENTS.md 时使用它实际支持的项目入口，不维护两份同内容规则。

```markdown
## Owner 工作约定
- 本项目使用 owner-project-control；用户不必每轮提技能名。需要时读取已安装 Skill；不可用时报告缺失并遵循此入口，不假装已加载。
- Backlog 是唯一任务记录。一般提问直接答；持续工作用当前 Task；独立未授权想法先 Draft。网页编辑不自动授权执行。
- 当前批准意图：填写已有文档真实路径。当前接手入口：填写 handoff 真实路径。
- 开工或恢复时读当前 Task、直接引用的批准条款与证据，并核对相关 Git 和执行者状态；只读任务需要的文件。
- 当前 Task 未变的普通讨论不要求重新审批；产品范围、重要体验或投入明显改变时才请 Owner 判断。
- 一张卡只有一个写入负责人；不同窗口沿相同持久记录接手，不依靠聊天复制状态。
- 完成成果、重要研究结论或暂停前，Agent 更新当前记录并合理保存 Git 版本；未验证中间版本明确标注。
- 复用有效研究和检查点；证据失效只重验受影响部分。失败方向写适用条件，过时内容从当前 handoff 移除。
- 不全仓考古，不覆盖未知修改，不自行运行未授权 Builder / 全量处理，不新建主控、任务库或项目管理 UI。
```

接入后在新对话检查 Agent 能指出真实入口和当前任务。未做到就修入口或宿主配置，而不是要求 Owner 永久手动背一长串提示词。该检查验证加载链，不证明模型永不遗漏。
