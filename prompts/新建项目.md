# 新建项目启动词

复制下面内容，补上目标和工作位置即可。工具包安装在独立工具目录，不放进每个业务项目；已安装可直接使用。

```text
我想新建一个项目。
工作位置：[目录；不确定时请推荐一个独立项目目录]
我要解决的问题：[用自己的话说]
本次希望得到的最小可用结果：[一句话；不清楚时帮我收窄]

使用我的 Owner 工作方式：
https://github.com/shira-qwq/owner-workflow-kit
先检查是否已安装 owner-project-control 和 owner-plain-language-zh；没有时按该仓库 README 安装，已有则复用，不每个项目重复 clone。

帮我建立最小批准范围、必要 Backlog 任务、Git 保存和短项目入口，实际打开并核对这个项目的 Backlog Web UI。Backlog 程序使用官方发布，项目任务和代码保存在我自己的项目仓库；没有远端时先本地保存，不向第三方仓库推送。

技术选择你负责。新能力先查项目已有能力和成熟方案，不确定时先有界研究或最小试验。我的随口想法先 Draft，不代表立即施工；已经明确授权的范围不用反复批准。

可以合理整理外层目录和散落产物，先检查依赖并保存可恢复版本。不要为了整齐破坏包内路径、配置、资源引用或数据位置。文档、研究、地图和小证据集中在现有或必要的文档目录，临时和运行输出单独放；不要在根目录生成一堆报告和最终版。

按需生成我能看懂的功能或数据局部图，沿用稳定名称并链接证据；不为初始化生成全仓文件地图或新主控。长任务先样本、实测速度、保存断点。

完成或暂停时更新任务与接手记录，主动建立合理保存点，告诉我能用了什么、尚未验证什么、下一步最值得做什么。
```
